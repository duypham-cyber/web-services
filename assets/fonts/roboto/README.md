# Roboto (chỉ dùng để dựng ảnh OG)

Roboto, Apache License 2.0 (https://github.com/googlefonts/roboto-3-classic). Tải từ Google Fonts ngày 06/10/2026, 3 subset
woff2 của bản biến thiên (weight 100–900).

Website KHÔNG tải file này: chữ trên web dùng bộ font hệ thống (D-32, styles/tokens.css). Máy dựng ảnh (bbsw, Linux) không có
Segoe UI, SF Pro hay Roboto, nên `scripts/gen-og-images.mjs` nhúng Roboto vào trang lúc chụp để ảnh chia sẻ dùng đúng một font
trong bộ đó.
